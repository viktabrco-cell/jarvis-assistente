JARVIS

Política de Privacidade

Última atualização: 30 de outubro de 2026.

Quem usa

O JARVIS é um assistente pessoal de uso privado, instalado e operado pelo próprio usuário no computador e no celular dele. Não há contas no JARVIS, servidores do JARVIS nem venda de dados.

Dados do Google

Com autorização do usuário (OAuth), o JARVIS acessa a Google Agenda, o Gmail, o Drive, o Docs, o Sheets, o Tasks e os Contatos apenas para cumprir pedidos feitos pelo próprio usuário — por exemplo, “quais são meus compromissos de amanhã?” ou “agende uma reunião às 10h”.

  • Os dados são processados no dispositivo do usuário e não são enviados a terceiros.
  • Os dados não são usados para publicidade nem para treinar modelos de inteligência artificial.
  • As credenciais de acesso ficam guardadas no chaveiro (Keychain) do sistema do usuário.
  • O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O usuário pode desconectar a conta a qualquer momento nos Ajustes do JARVIS ou em myaccount.google.com/permissions. Ao desconectar, as credenciais são apagadas do dispositivo.
